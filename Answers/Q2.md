主串 S 长度 n

模式串 P 长度 m

``` python
Input:
    S[0..n-1]       // 主串
    P[0..m-1]       // 模式串（含?）
Output:
    matches[]       // 匹配起始位置数组

从 a 匹配到 z，
如果在一个长度位m的区间中，在相同的位置存在相同的字母，则该区间的匹配分数+1

score[n-m] : 第i个表示 S[i,i+m] 与 P[i,i+m] 的匹配的字母的个数
matches[n-m] ：第i个表示 S[i,i+m] 与 P[i,i+m] 完全匹配

外层循环：
for c in a~z:
    A[n]
    B[m]
     
    for i from 0 to n-1:
        if S[i] == ch:
            A[i] = 1
        
    for i from 0 to m-1:
        if P[i] == ch:
            B[i] = 1

    卷积定义：
        A =     [a_0 .. a_(n−1)]
        B =     [b_0 .. b_(m-1)]
        A * B = [c_0 .. c_((n + m) - 2)]  // c_k = (a_i)(b_j) for i+j=k

        卷积长度： ((n)+(m)-2) + 1 = n + m - 1

    计算卷积
        找到 至少 n + m - 1 的 powers of 2, 设为 t

        把 A 和 B 填充 0 直到长度为 t, 反转B

        计算卷积：
        F_A = FFT(A)
        F_B = FFT(B)
        F_C = F_A 点乘 F_B
        CONV_A_B = IFFT(F_C)              

        // 有在相同位置的字母 1x1=1, 不相同的字母 1x0=0，0x1=0.
        for i from 0 to n-m-1:
           score[i] += C[i + m - 1]

检擦匹配字母个数
for i from 0 to n-m:
    if score[i] == (m - P中?的个数):
        matches[i] = 1

return matches
```
时间复杂度

外层循环 O(1) 26次

每次循环：

    构建A，B: O(n)

    填充0: O(n)

    两次FFT: O(nlog(n))

    点乘FFT: O(n)

    一次反FFT：O(nlog(n))

    计算score：O(n)

计算matches：O(n)

总共：O(nlog(n))
